プライバシーポリシー

最終更新日: 2026年11月11日 · 運営: StudentFood 運営（三摩 琉）

StudentFood運営者（以下「当運営」）は、iOSアプリ「StudentFood」（以下「本アプリ」）における利用者情報の取り扱いについて、以下の通りプライバシーポリシーを定めます。

1. 取得する情報とその目的

本アプリは「空きコマ90分。決め手3秒。」のコンセプトに基づき、必要最小限のデータのみを取り扱います。

(1) 店舗検索に必要な情報

  • 位置情報（現在地）: 周辺飲食店を検索し、徒歩分数・距離を計算するためにのみ使用します。利用者の許可を得た場合のみ取得します。周辺検索や経路計算に必要な座標を、当運営の検索APIおよび外部の地図・店舗情報サービスへ送信して処理します。拒否された場合でも固定地点（大学・駅）から検索可能です。
  • 検索条件: 選択したモード、予算、徒歩時間などの条件は端末内に保存し、検索に必要な条件を当運営の検索APIや外部の店舗情報サービスへ送信します。

(2) 学生証パス・認証機能（App Functionality）

  • 大学メールアドレス（@kansaigaidai.jp 等）: 学生証パス発行時の大学ドメイン・メール所有確認およびワンタイム認証コード（OTP）送信に使用します。認証基盤では、メールアドレス、大学識別子、照合用コードハッシュ、有効期限、送信状態等を一時保存します。平文の認証コードは認証データベースに保存せず、不正送信抑制用のネットワーク識別子はハッシュ化します。認証情報は作成から24時間を経過すると定期削除の対象になり、実際の削除時刻は処理の実行状況により異なります。メール配信サービス側の記録には、各事業者の保存方針が適用されます。大学メールの所有確認は、大学による公式な在籍証明ではありません。
  • 氏名・大学名・会員番号・来店履歴: 学生証パスの氏名・大学名・会員番号・来店履歴は端末内に保存します。氏名・来店履歴を当運営のサーバーへ登録する処理はありません。認証のために大学識別子を送信し、会員番号は認証成功時にサーバーで採番します。

会員証QRの提示: パス裏面の会員証QRには、メールアドレス、会員番号、大学識別子、表示時刻が含まれます。QRを読み取った相手はこれらの情報を取得できます。提示先を確認してご利用ください。

(3) 利用分析（Analytics / 任意・同意者のみ）

設定画面で「匿名の利用データを共有」に同意いただいた場合のみ、品質向上のために以下の利用情報を収集します。ランダムなIDにより、同じ端末からの操作を区別できます。

  • ランダム生成された匿名インストールID、アプリ/OSバージョン
  • 選択モード、約1km単位に丸められた地域情報（精密座標ではありません）
  • 店舗候補の表示・操作ログ、検索時間、エラー情報
※ 氏名、大学メールアドレス、Apple ID、学籍番号、広告識別子（IDFA）、正確なGPS座標が分析データに含まれることは一切ありません。

2. 利用者によるデータの管理・削除権利

設定画面から、端末内の学生証パスとサーバーの利用分析データをそれぞれ管理できます。各操作の削除対象は以下のとおりです。

  • 学生証パスの完全削除: 本アプリの設定画面内「学生証パスと登録データの削除」より、端末内の氏名・メールアドレス・会員番号・来店履歴を即座に完全消去できます。
  • サーバー送信データの削除: 設定画面内「サーバーの利用データ・送信記録を削除」より、サーバーに送信された匿名分析データの削除をいつでも要求・実行できます。
  • 同意の変更: 設定画面のトグルより、いつでも分析データ共有のオン/オフを切り替え可能です。既に送信した分析データの削除は、上記のサーバーデータ削除を別途実行してください。

端末内のパス削除は、認証基盤やメール配信サービス側の記録を一括削除する操作ではありません。これらについてのお問い合わせは下記窓口へご連絡ください。

3. 広告トラッキングおよび第三者提供について

  • 広告トラッキングを行いません: 他社のアプリやWebサイトを横断して利用者を追跡する広告識別子（IDFA / ATT）は一切取得・使用しません。
  • 第三者へのデータ販売・提供の禁止: 法令に基づく場合を除き、利用者のデータを広告目的や営利目的で第三者へ販売・提供・譲渡することはありません。

4. 外部サービス

本アプリは機能提供のために以下の事業者サービスを利用しています。

  • Apple Maps (MapKit): 地図・経路表示および徒歩分数の計算
  • ホットペッパーグルメ Webサービス (リクルート): 周辺飲食店の店舗情報取得
  • Supabase: 店舗カタログ・検索API・利用分析データ・一時的な認証基盤
  • Google Apps Script / メール配信: 大学メールアドレスへの認証コード送信処理
  • GitHub Pages: 本ポリシー・サポートページの配信。GitHubは安全性確保のため、Webページ訪問者のIPアドレスを記録します。
